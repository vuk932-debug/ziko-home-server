# Production Switch Guide: OTP & Reset System

This document provides clear instructions on how to transition the ZikoHome OTP system from **Development/Staging** (Dev-UI/Console) to **Production** (Email/SMS).

---

## 1. Environment Configuration

To move to production, update your `.env` file on the production server (Render, Vercel, etc.):

### Step A: Change OTP Mode & Toggle Routes
Set `OTP_MODE` to your desired production channel and DISABLE dev routes.

```env
NODE_ENV=production
OTP_MODE=email  # OR sms
ENABLE_DEV_OTP_ROUTES=false # STRICTLY false in production
```

### Step B: Secure Dev Endpoints
Ensure `DEV_OTP_SECRET` is changed to a long, random string. This secret is required for any dev-mode API calls.

```env
DEV_OTP_SECRET=your_long_random_production_secret
```

### Step C: Configure Providers
If using `email` mode, ensure your `RESEND_API_KEY` is set.

```env
RESEND_API_KEY=re_123456789...
```

---

## 2. Frontend OTP Viewer (Internal Tool)

A temporary web interface has been added for testing purposes:
👉 **URL:** `/dev-tools/otp-viewer`

### Features:
- Search for OTPs/Tokens by Email or Phone.
- Fetch the 10 most recent codes generated by the system.
- Securely locked behind the `DEV_OTP_SECRET`.

### How it works in Production:
When you set `ENABLE_DEV_OTP_ROUTES=false` in your server environment:
- The backend routes for this tool are **NOT mounted**.
- Any request from this page will return a `404` or `403`.
- The tool becomes safely inert without any frontend code changes.

---

## 3. Code Implementation (Production Channels)

The architecture is designed so you ONLY need to modify `src/api/v1/services/delivery.service.ts`.

### Email Delivery
Implemented using Resend. To change providers, update `src/api/v1/services/resendEmail.service.ts`.

### SMS Delivery (Action Required)
To enable SMS, implement the placeholder in `src/api/v1/services/delivery.service.ts`:

```typescript
if (mode === 'sms') {
  // 1. Import your SMS provider (e.g., Twilio)
  // 2. await twilio.messages.create({ body: `Your code: ${code}`, to: identifier, ... });
  return;
}
```

---

## 4. Security Checklist for Production

- [x] **NODE_ENV:** Set to `production`.
- [x] **ENABLE_DEV_OTP_ROUTES:** Set to `false`.
- [x] **Database Migration:** Apply schema changes: `npx prisma migrate deploy`.
- [x] **Rate Limiting:** Verify `authLimiter` is active in `src/app.ts`.
- [x] **Secrets:** Ensure `JWT_SECRET` and `DEV_OTP_SECRET` are rotated.

---

## 5. Testing the Production Switch
To test production mode locally:
1. Set `OTP_MODE=email` and `ENABLE_DEV_OTP_ROUTES=false`.
2. Provide a valid `RESEND_API_KEY`.
3. Try the login/forgot password flow.
4. Verify you receive the actual email and the `/dev-tools/otp-viewer` page fails to fetch data.
